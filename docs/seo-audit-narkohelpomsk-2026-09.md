## 1. Короткий вывод

Сайт технически «живой»: HTTPS, редиректы на www, canonical, Open Graph, счётчики, коммерческие посадочные и ~280 URL в sitemap. При этом **по коммерческим запросам «лечение / реабилитация + Омск» сайт почти не виден в топе**: выдачу держат федеральные SEO-сетки наркологических клиник, агрегаторы и справочники.

Сильные стороны:

- брендовые запросы — **топ-1**;
- информационные запросы родственников — проблески видимости;
- 2ГИС: оценка **5.0 / 76 отзывов**;
- регулярный блог (208 постов, свежие материалы августа 2026);
- честная позиция «медуслуги — у лицензированного партнёра».

Слабые стороны, которые режут ранжирование в Яндексе и Google:

- в Яндекс Картах **две карточки на одном адресе** (Декабристов 37): основной «Импульс» [199394486863](https://yandex.ru/maps/org/impuls/199394486863/) и женский «Импульс Плюс» [56854615182](https://yandex.ru/maps/org/impuls_plyus/56854615182/). Поиск «реабилитационный центр импульс омск» может открыть Плюс — каннибализация бренда. Третью карточку не заводить;
- конфликт идентичности: в разметке `MedicalClinic`, в мета — «социальная помощь, медуслуги у партнёра»;
- каннибализация посадочных (алкоголь / нарко / цены / игромания);
- тяжёлая главная (~262 KB HTML, 47 script, 93 img);
- новости с кириллицей и эмодзи в URL;
- SearchAction в schema ведёт на `/?s=`, который **закрыт** в robots.txt.

**Реалистичная цель на 3–6 месяцев:** топ-3 по бренду и локальным картам; топ-10 по 8–12 среднечастотным коммерческим запросам Омска; рост информационного трафика с блога родственников.

### 2.2. Счётчики и аналитика

На главной подключены:

- Яндекс.Метрика **96462627** (плагин wp-yandex-metrika);
- Google Tag Manager: в `<head>` грузится **GTM-PBHDQPHM**, в noscript iframe — **GTM-58HTBZ9X**. Это рассинхрон пары (не два полных контейнера), но счёт идёт в разные ID; noscript должен совпадать с script;
- Mail.ru Top **3554215**;
- Cloudflare Turnstile на формах.

Рекомендация: оставить один GTM, в нём — Метрика + GA4. Проверить цели: звонок (`tel:`), отправка CF7, клик Telegram, скролл, время на странице.

### 2.3. Производительность

Главная: HTML ~262–276 KB, **93 изображения** (2 без alt), 17 внешних script src + всего 47 `<script>`, 68 упоминаний webp, но также jpg/png. Есть lazy-load (58), dns-prefetch/preconnect.

Для Яндекса это бьёт по поведенческим (отказы на 4G). Для Google — Core Web Vitals. Нужен отдельный прогон PageSpeed/Вебвизор; публичный PSI API в этой среде не вернул метрики.

Приоритет ускорения:

1. отложить некритичные скрипты (лишний GTM-ID, bvi, swiper на первом экране);
2. hero в AVIF/WebP с явным `width/height`, без CLS;
3. не грузить всю команду и все отзывы в DOM сразу — пагинация/аккордеон;
4. кэш HTML (плагин/nginx), сейчас `max-age=0`.

### 2.4. Критичные технические дефекты

1. **SearchAction** в JSON-LD: `https://www.narkohelpomsk.ru/?s={search_term_string}`, при этом `Disallow: /?s=`. Либо открыть поиск, либо убрать SearchAction.
2. Страница `/rasschitat-stoimost/` — **нет H1**.
3. URL `/prise/` — опечатка *price*. Есть дубль `/czeny-na-reabilitacziyu-alko-i-narkozavisimyh/` с **тем же H1**.
4. Смешение транслита: `reabilitaciya` и `reabilitacziya` (cz). Путает людей и дробит вес.
5. Новости: **58 из 78** URL в `news-sitemap.xml` с кириллицей в slug, плюс эмодзи (`/news/весна-😍/`) и старые URL 2019 года. Плохо индексируются, выглядят как малоценный контент. Список: `docs/seo-fixes/news-cyrillic-slugs.txt`.
6. `sameAs` на 2ГИС: кабинет `https://account.2gis.com/orgs/70000001033512038` (неверный ID). Публичная карточка — `https://2gis.ru/omsk/firm/70000001033512039`.
7. Индексный sitemap для страниц `lastmod` — май 2026, хотя контент блога свежий. Обновлять даты при правках.

## 4. E-E-A-T / YMYL (критично для Google и качества Яндекса)

Ниша — **Your Money Your Life**. Google жёстко фильтрует медсайты без экспертизы. Яндекс снижает сайты с вводящими обещаниями и сетками «клиник».

Факты по сайту:

- Юрлицо: АНО «ЦСП «Импульс»», ИНН 5504151921, ОГРН 1175543039913, с 15.12.2017. ОКВЭД **87.90** (уход с проживанием), не медицина.
- Юридический адрес: Жукова 74 к.2 оф.504. Приём: Декабристов 37 оф.25. В schema postalCode **644000**, в 2ГИС **644070**.
- Страница `/licenziya/`: «Импульс не оказывает медуслуги», лицензия партнёра ООО «ДА-компани».
- При этом schema.org тип **`MedicalClinic`** и тексты про лечение/детокс/врачей.

Это главный риск санкций и недоверия:

- Google может не давать топ по «лечение наркомании»;
- Яндекс — фильтры качества / «медицинский» ИКС.

**Правильная модель разметки:** `NGO` или `LocalBusiness` + `Service` (социальная реабилитация) + отдельный блок про партнёра-медучреждение с лицензией. Не `MedicalClinic` на АНО.

На страницах специалистов указать: ФИО, должность, образование, стаж, ссылка на диплом/сертификат, авторство статей. Сейчас команда есть, но статьи блога часто без автора-эксперта.

## 6. Почему коммерция не ранжируется

1. **Сетки клиник** (Трезвый Путь, Частный Медик 24, Евро-Клиник, Калюжная) штампуют отдельные URL под каждый ключ + цена в title + таблица + локальные поддомены `omsk.*`.
2. У нас **несколько URL на один интент** — вес размазан.
3. Title главной ушёл в «консультации и социальная помощь», а спрос — «лечение/реабилитация».
4. Две карточки Яндекс на одном адресе: основной запрос в Картах может уехать на «Импульс Плюс»; у основной мало отзывов (15 vs 76 в 2ГИС).
5. YMYL: тип клиники в schema при отсутствии медлицензии у АНО.
6. Слабые внешние ссылки с тематических доноров ( apart from КП, 2ГИС, VK).

Это не «сайт плохой». Это сайт **не заточен под коммерческий интент** и проигрывает фабрикам посадочных, при этом честнее их юридически.
